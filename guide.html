1 · Build every deliverable one command

The whole pipeline is deterministic — one npm script generates the 36 skins, capes, both Bedrock packs, cover, icons, poster, and the Fabric mod, then validates each Bedrock pack against Microsoft's official skin-pack spec:

npm run trailer

Everything lands in two places: dist/ (installable artifacts) and asset folders (pack/, starter-pack/, icons/, poster/, cover/).

Spec compliance is enforced, not hoped for. Both exporters run exportValidMcpack() — if the zip deviates from learn.microsoft.com's Packaging a Skin Pack doc in any way (manifest shape, skins.json fields, texture placement, .lang keys, languages.json), the build fails with every violation listed.

2 · QA the pack visually 10 minutes

Open the pages in this order and check each item:

a
gallery.html — all 36 cells render, capes visible on hover, click-through works, no console errors (F12).
b
search.html — filter pink-cyan + white-messy, expect 144 / 4320 matches; open one result and confirm the deep-link lands on the right skin.
c
index.html — cycle all 4 animations, toggle the cape, confirm the bloom glow follows the neon trim.
d
Bedrock self-install — double-click dist/VOXEL-CYBER-STREET.mcpack, open Minecraft Bedrock → Profile → Skins, confirm the pack appears with its localized title and every skin name renders (switch the game language to Deutsch / Français / 日本語 to see the translations swap).

3 · Assemble the press kit browser, no upload

presskit.html inventories every deliverable, then zips them client-side into one archive for submissions and partner applications:

open presskit.html → ⬇ Build press kit zip

The kit contains the cover, A3 poster, all 41 store icons, both .mcpacks, the Fabric jar + source, skin/cape PNGs, pack indexes and a generated README.txt. The page shows a live ✓ / ✗ per file — anything missing tells you exactly which build step to re-run.

4 · Record the marketing trailer 15 s or OBS

Two options, fastest first:

a
One-click capture — open gallery.html?trailer=1 (or press ● Trailer). It drives a scripted 6-shot sequence — title card, cape sweep, variant sweep, animation spotlight, full turntable, end card — and auto-downloads voxel-cyber-street-trailer.webm (1280×720, VP9). The full VO script for this cut is in TRAILER.md.
b
OBS master — record the live gallery at 1080p60 with the shot list in TRAILER.md as your storyboard. Marketplace listings convert measurably better with motion in the first three seconds.
The trailer only exists after a recording pass — the press kit page flags it as ✗ until you've captured one. Record before building the final zip.

5 · Ship on the platforms you can reach today no gate

While the Marketplace application is in flight, the pack ships anywhere else:

Bedrock — direct

The .mcpack installs by double-click on any Windows/Android/iOS Bedrock instance — share it on itch.io, Gumroad, or your own site. Non-partner packs must mark every skin type: free (ours already do) and can't appear in the in-game store.

Java — mod portals

voxel-cyber-street-fabric-1.21.jar drops into .minecraft/mods and applies the skins + glowing capes to NPCs. Submit to CurseForge/Modrinth with the cover + trailer; link the src zip for review.

6 · Apply to the Marketplace partner program the real gate

Skins can only be sold inside the in-game Marketplace by approved partners. The path:

1
Read the partner overview at minecraft.net/partners — Minecraft handles store curation through selected partner studios and programs rather than open self-serve listings.
2
Prepare what every application asks for: a portfolio (your gallery + reference sheet pages), store-ready assets (the press kit zip: cover, icons at 512², trailer), and a team/business identity (partners generally work as registered studios; solo creators usually partner with an existing studio as an artist).
3
Submit through the partner application form and reference your press kit. Expect review focus on art consistency (our 36 skins are one generator family — a strength), localization (4 languages ship in the box), and technical compliance (machine-validated against the packaging doc).
4
Once accepted, flip skin type entries to paid in the exporter config, re-run npm run trailer, and resubmit — the validator accepts both values.
Reality check: approval is competitive and Mojang/Microsoft currently onboard partners in cohorts. The direct Bedrock + Java routes in step 5 build the sales history and audience that make an application credible.

7 · Keep the pipeline green maintenance

Any content change re-runs through the same gates:

  • npm run pack — regenerate skins after touching skin-gen-core.js
  • npm run trailer — rebuild + revalidate all artifacts
  • The spec validator fails the build on any deviation — never bypass it; fix the exporter instead
  • Re-record the trailer after any visual change so the press kit stays current
